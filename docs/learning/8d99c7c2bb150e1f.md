# Learning proposal: Use supported Chrome rendering flags in web verification

Status: proposed; human review and merge required.

## Observed problem

The verifier's unconditional GPU-disable flag is rejected by the available headless Chrome configuration, causing GPU initialization errors during Flutter Web runtime checks.

## Proposed improvement

Use an explicit supported software-rendering path or a controlled fallback for headless Chrome, then validate screenshot rendering and preserve browser console/error gates.
