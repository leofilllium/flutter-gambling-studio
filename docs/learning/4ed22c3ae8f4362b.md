# Learning proposal: Pin compatible flame_audio in autocreate

Status: proposed; human review and merge required.

## Observed problem

The autocreate runbook names flame_audio without the existing compatible version, allowing an incompatible dependency choice with Flame 1.18.x.

## Proposed improvement

Reference the canonical flame_audio ^2.1.0 constraint directly in the autocreate scaffold instructions and validate dependency resolution.
