# Web fallback font guidance review

Observed before/after: Flutter3.44.5 CanvasKit requested Roboto from fonts.gstatic.com despite bundled Rye/Nunito and the no-CDN flag. Installed engine fonts.dart lines99–115 confirmed the missing family trigger. Registering the existing local font under the fallback alias yielded zero remote requests and zero errors in fresh-cache external-traffic-blocked startup plus eight real spins. A generated-manifest regression verifies the local alias. Evidence paths and version are retained in the helper report.

The technical-preferences addition asks for measurement before an offline-resource claim, scopes the alias workaround to confirmed engine behavior, and distinguishes local server availability from PWA installation. It preserves every original technical-preferences line, secure RNG, math, asset and platform rules. It introduces no new skill, engine patch, mandatory font identity, network dependency, or permission flow. A structured validation checks additive-only scope, the conditional wording, exact observed version, preserved original content, actual evidence counts and required error/request assertions. Native packaging remains outside this experiment.
