# Learning proposal: Audit deep-link routing through loading and retry states

Status: proposed; human review and merge required.

## Observed problem

The temporary Flutter loading MaterialApp inherited a non-root Web platform route before game routes existed, logging an initial-route error even though the loaded app later preserved saved state. Explicit initialRoute alone was overridden by platform defaultRouteName.

## Proposed improvement

Extend the existing UI-audit C1 route check to cover non-root browser reloads through loading/error/retry; keep bootstrap navigation separate until services are ready and test platform route precedence.
