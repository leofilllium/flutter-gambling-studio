# Learning proposal: Default carousel slices to hidden publisher seams

Status: proposed; human review and merge required.

## Observed problem

Zero-gutter triptych exports can look correct edge-to-edge but jump when a publisher inserts approximately 100-pixel separators between 1320-pixel carousel cards.

## Proposed improvement

Default triptych carousel slicing to an automatic seam allowance scaled from 100 pixels at 1320 width; reserve zero gutter for explicitly lossless/butt-jointed output, and test both behaviors.

Base commit: `da798a33fa2b5bf8a3a1c3e0dd4d46991930b402`

    Source: user correction during carousel artwork revision, 2026-09-15.

    Observed failure:
    Three independently butted carousel crops can look aligned in a zero-gap panorama preview yet produce abrupt visual jumps when the publisher UI inserts separators between the cards.

    Verified presentation contract:
    For 1320-pixel-wide carousel cards, the source artwork must continue beneath approximately 100 pixels at each inter-card separator. Exporting therefore discards a 100-pixel source strip at each cut while preserving the continuous scene behind the publisher gap. Critical faces, inscriptions, and decisive gameplay outcomes must stay outside those hidden strips; only atmosphere and noncritical board structure may cross them.

    Impact:
    Without a default hidden-strip allowance, characters and gameplay fields can appear to jump or mismatch across store cards even when the edge-to-edge panorama preview looks correct.

    Reusable improvement:
    Make the triptych carousel default use an automatic seam allowance equal to 100 pixels at a 1320-pixel card width, scaling proportionally for other sizes. Keep an explicit zero-gutter option for lossless diagnostic panoramas or publishers known to render true butt joints. Update the skill guidance, command help, and slicing tests together.

    Verification target:
    Unit tests must prove that the default resolves to 100 pixels for 1320-pixel cards, that the corresponding source strips are omitted, and that explicit zero-gutter slicing still reassembles losslessly.
