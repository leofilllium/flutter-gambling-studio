# Learning proposal: Generate store panoramas as one integrated scene

Status: proposed; human review and merge required.

## Observed problem

The store skill permits compositing a gameplay screenshot or board plate into a scene after generation, leading to a visibly pasted field.

## Proposed improvement

Require gameplay captures to be context references for a single complete panorama generation; remove the deterministic board-paste fallback and block delivery if gameplay truth cannot be preserved.
