# Learning proposal: Verify engine fallback fonts before claiming offline Web startup

Status: proposed; human review and merge required.

## Observed problem

Bundling app font families and disabling the Web resources CDN did not prevent a remote Roboto request in Flutter3.44.5 CanvasKit because its font loader checks for a specific fallback family in FontManifest.

## Proposed improvement

Add version-scoped diagnostic guidance to technical preferences: inspect actual engine fallback behavior and verify a fresh cache with external requests blocked; when appropriate register a bundled fallback alias and preserve the app typography.

Base commit: `15445729f6dea385c4a6edb525fd49ffc77bc17b`
