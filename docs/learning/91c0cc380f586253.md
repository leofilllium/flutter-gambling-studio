# Learning proposal: Cancel delayed visual handoff timers

Status: proposed; human review and merge required.

## Observed problem

A Future.delayed used to keep an image-loading fallback visible left a pending timer when the widget was disposed, failing layout tests.

## Proposed improvement

Use a nullable Timer owned by the widget, cancel it in dispose, and keep the mounted guard before setState for delayed fallback removal.

Base commit: `270fa70ccefd4dabc7bd569cf09f08cee7cb0149`
