# Learning proposal: Rank primary gameplay actions ahead of help labels

Status: proposed; human review and merge required.

## Observed problem

The first-match generic play selector can match a How to Play navigation label before the actual start-game action.

## Proposed improvement

Prioritize exact and primary gameplay labels and rank candidates so help/navigation text does not trigger the gameplay action; retain fallbacks for varied games.

Base commit: `9973eefd5b68e4cddce9bb4a3f58fd45bdd044d1`
