# Learning proposal: Make Chrome semantic tours prefer leaf controls and preserve CanvasKit raster assets

Status: proposed; human review and merge required.

## Observed problem

The runtime verifier selected a composite Flutter semantics node instead of the leaf action control, and disabled-GPU CanvasKit captures omitted PNG textures while text still rendered.

## Proposed improvement

Use exact-match leaf-control selection in tools/web_verify.mjs and launch headless Chrome with ANGLE SwiftShader GPU flags so CanvasKit raster assets decode in verification.

Base commit: `71c0db319a55590b468b45105ff398b217e58813`
