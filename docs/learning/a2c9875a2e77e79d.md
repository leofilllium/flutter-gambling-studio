# Learning proposal: Cover reentrant notifier release during lifecycle checks

Status: proposed; human review and merge required.

## Observed problem

A wallet listener released its own controller during notification, causing dispose-during-notify and concurrent Set modification errors and skipping another controller refresh.

## Proposed improvement

Extend existing UI lifecycle guidance with stable listener snapshots, inactive-first ownership and deferred notifier teardown, backed by a reentrant release regression scenario.

Base commit: `15445729f6dea385c4a6edb525fd49ffc77bc17b`
