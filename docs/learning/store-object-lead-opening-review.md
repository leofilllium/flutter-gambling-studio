## Scenario review

| Scenario | Expected routing | Review result |
|---|---|---|
| Shining Crown, object lead, no living character | No invented human, hand, animal, mascot, or player silhouette; authentic three-quarter gameplay is visible in slides 1 and 2 | PASS |
| Cosmic Plinko, mechanic lead, no living character | No invented person or mascot; the real angled mechanic is visible in slides 1 and 2 | PASS |
| Joker slot, character lead | Existing large-character first-panel default remains authoritative | PASS |
| Chicken risk game, living animal character | Existing species-appropriate character framing remains authoritative | PASS |
| One board spans the first two crops | Both separate crops must contain meaningful gameplay; the assembled panorama alone is insufficient evidence | PASS |
| Royal props frame a slot scene | Props may support the composition but cannot replace first-slide gameplay | PASS |

## Consistency findings

- The rule is conditional on an object/mechanic lead and the absence of a living character in the concept and shipped inventory; it does not suppress real characters.
- Planning, composition, crop-level review, and final reporting all carry the same invariant.
- The Shining Crown example now agrees with the canonical store workflow.
- Actual topology, symbols, and resolved state remain authoritative, so the three-dimensional presentation cannot invent gameplay.
