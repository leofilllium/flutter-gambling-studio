# Learning proposal: Require contextual integration for angled gameplay

Status: proposed; human review and merge required.

## Observed problem

A truthful perspective-warped gameplay field still read as a pasted rectangle because the scene did not structurally, photometrically, or atmospherically receive it.

## Proposed improvement

Add an explicit contextual-embedding contract and focused regression assertions for structural housing, contact light/shadow, and overlap cues; perspective alone must not count as integration.

    Observation
    ===========

    In a Zeus: Thunder Match store-carousel revision, the authentic gameplay field was
    perspective-warped and placed over a decorative marble area. The topology was truthful,
    but the field still read as a pasted rectangular sample because the surrounding scene did
    not physically receive it. The user explicitly requested that gameplay be used as scene
    context and appear as a naturally integrated 3D angled surface.

    Existing guidance
    =================

    The store-screenshots skill already said that a pasted screenshot rectangle fails and that
    the deterministic fallback is not permission to paste an unintegrated rectangle. The
    focused regression test only checked for that sentence and for topology/fallback ordering;
    it did not make the observable integration cues discoverable or testable. This is therefore
    an execution/discovery and validation gap, not a missing high-level prohibition.

    Verified correction
    ===================

    The revised composition first created a scene-native, thick gold-and-marble storm altar
    with a clean recessed opening. The exact deterministic 7x7 gameplay field was then mapped
    as one complete layer into the altar plane. The surrounding housing provides slab depth,
    contact shadow, reflected cyan/gold light, lightning at the frame, and foreground overlap.
    The final field remains 49 cells with the decisive three-symbol result unchanged and wholly
    inside one panel. The three 1320x2868 exports passed the strict App Store composition and
    shape checks.

    Proposed reusable improvement
    ============================

    Add a small contextual-embedding contract beside the deterministic fallback: when angled
    or environmental gameplay is requested, perspective warp alone is not completion. Require
    observable evidence from three categories while keeping topology readable: structural
    housing/depth, photometric contact/light response, and an overlap/atmospheric interaction.
    Extend the focused guidance regression test to keep those cues discoverable and prevent the
    rule from regressing into a phrase-only warning.
