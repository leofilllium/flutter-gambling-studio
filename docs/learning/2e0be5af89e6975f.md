# Learning proposal: Keep generated image payloads out of text logs

Status: proposed; human review and merge required.

## Observed problem

Whole built-in image-generation results were serialized through notify or text, flooding tool output with base64 and truncating useful status.

## Proposed improvement

Add concise result handling to existing technical preferences: use generatedImage for image presentation and log only path or status fields, preserving art files and review gates.

Base commit: `15445729f6dea385c4a6edb525fd49ffc77bc17b`
