# Learning proposal: Activate Flutter accessibility without tapping game controls

Status: proposed; human review and merge required.

## Observed problem

The browser verifier clamps an offscreen Flutter accessibility placeholder to1,1 or blindly taps1,1 when absent, hitting Back instead and leaving semantic labels unavailable.

## Proposed improvement

Activate the actual accessibility placeholder directly with shadow-root traversal; remove blind accessibility taps and retain physical taps for real game actions. Add functional DOM regression coverage.

Base commit: `15445729f6dea385c4a6edb525fd49ffc77bc17b`
