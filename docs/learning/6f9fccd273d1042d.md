# Learning proposal: Close legacy panorama gameplay paste path

Status: proposed; human review and merge required.

## Observed problem

The store skill requires one generated scene, but the compositor still exposes a gameplay boardplate and sprite inlay route that can paste a capture into panorama panels.

## Proposed improvement

Make triptych slice only a complete generated image, retire the boardplate CLI entrypoint, and align CLI help with the capture-as-context workflow.
