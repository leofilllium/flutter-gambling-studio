# Learning proposal: Verify the store compositor Python interpreter before use

Status: proposed; human review and merge required.

## Observed problem

Store screenshot preflight and examples invoke python3 without discovering the existing project interpreter; missing Pillow or numpy aborts compositor help even when the project virtual environment already has both.

## Proposed improvement

Update the existing store-screenshots preflight to discover and verify an existing Python interpreter, then reuse its quoted path in every compositor example before suggesting installation.
